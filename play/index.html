Soul Deckbuilder

드로우, 카드 사용 등 모든 행동에 '영혼'을 사용하는 로그라이크 덱빌딩 게임입니다.

조작법 & 규칙

  • 숫자키 (1~9) : 손패의 카드 사용
  • Shift : 턴 종료
  • Spacebar : 확인 / 넘어가기
  • 마우스 : 버튼 클릭 및 선택
  • 전투 시작 시 영혼 +15 획득
  • 턴 시작 시 3장 자동 드로우 (무료)
  • 상점에서 50~70 영혼으로 패시브 능력을 가진 유물(Relic) 구매 가능
