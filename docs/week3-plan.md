## 5️⃣ 스테이지 1 만들어 보기

> 📌 게임 전체가 아니라 **첫 번째 스테이지 하나만** 생각합니다. 스테이지 1을 만들려면 무엇이 필요한지 적어 봅니다.

### 5-1. 스테이지 1에서 일어나는 일

| 구분 | 내 게임에서는 |
|---|---|
| ▶️ **시작할 때** | 체력 100,영혼 50으로 시작,기본적인 공격카드 4개,수비4개로 시작 |
| 🔄 **플레이 중** | 전투시 영혼을 15개, 매턴마다기본적인 카드는 3개씩 주고, 영혼을 사용하여 자신의 턴에 드로우, 카드 사용을 함, 전투가 끝날시 영혼을 10~20를 줌. 전투가 끝나고 길을 선택해 어디로 갈지 선택함 |
| 🏆 **클리어 조건** | 해당 스테이지의 보스를 처치시 |
| 💥 **실패 조건** | 체력을 모두 소진시 |

### 5-2. 스테이지 1에 등장하는 것들

게임 프로그램은 등장하는 것마다 **갖고 있는 정보**와 **하는 행동**으로 이루어집니다. 아래 표가 나중에 내 프로그램의 구조가 됩니다.

| 이름 | 갖고 있는 정보<br>(예: 위치, 목숨) | 하는 행동 또는 규칙<br>(예: 이동, 점프) |
|---|---|---|
| 🧍 **플레이어** | 체력,영혼 | 공격,방어,선택,영혼(자원) |
| 적 | 체력 | 공격,방어 |
| 이벤트 | 랜덤 | 랜덤 |
| 보스 | 체력 | 공격,방어 |
| 상점 |  | 유물,카드 등을 판매 |
| 영혼 | 카드의 드로우, 카드 사용의 코스트, 상점등에 사용되는 재화 |  |
| 맵 |  |  |

> 플레이어 외에 몬스터, 퍼즐, 아이템, 장애물 등 스테이지 1에 꼭 필요한 것만 적습니다. 부족하면 같은 모양으로 줄을 더 추가해도 돼요.
