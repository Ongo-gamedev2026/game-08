내가 만들고 싶은 게임을 정리해 옵니다. 모르는 칸은 비워 두고 발표 때 질문해도 괜찮아요.

> ✏️ **작성 방법:** 오른쪽 위 연필 ✏️ 아이콘을 누르고 빈칸에 내용을 적은 다음 **Commit changes**를 누르세요.

---

## 1️⃣ 이 게임을 한 문장으로 소개하기

> 예: 고양이가 떨어지는 생선을 받고 폭탄은 피하며 최대한 오래 버티는 게임

**답:** 드로우, 카드선택,코스트를 모두 하나의 자원으로 하는 로그라이크 덱빌딩게임

## 2️⃣ 타깃 플레이어

> 이 게임을 누가 할지 적습니다. 아직 못 정했으면 빈칸으로 둡니다.

**답:** 로그라이크, 턴제, 전략, 카드게임을 즐기는 사람

## 3️⃣ 레퍼런스 게임 (2~3개)

| 🎮 게임 이름 | 🏷️ 장르 | 👀 참고하고 싶은 점 |
|---|---|---|

## 4️⃣ 핵심 요소

> 이 게임에서 가장 중요한 재미 요소는 무엇인가요?

**답:** 자원의 조절, 시너지, 스팩업, 선택

---

## 5️⃣ 스테이지 1 만들어 보기

> 📌 게임 전체가 아니라 **첫 번째 스테이지 하나만** 생각합니다. 스테이지 1을 만들려면 무엇이 필요한지 적어 봅니다.

### 5-1. 스테이지 1에서 일어나는 일

| 구분 | 내 게임에서는 | 예시 |
|---|---|---|
| ▶️ **시작할 때** | 시작지점에서 시작 | 플레이어가 화면 아래에 서 있다 |
| 🔄 **플레이 중** | 적을 카드를 사용해 처치해 진행.<br>다음 스테이지를 선택해 진행. | 위에서 생선과 폭탄이 떨어진다 |
| 🏆 **클리어 조건** | 해당 스테이지의 보스를 처치시 | 생선 10개를 받으면 성공 |
| 💥 **실패 조건** | 체력을 모두 소진시 | 폭탄에 3번 맞으면 실패 |

### 5-2. 스테이지 1에 등장하는 것들

게임 프로그램은 등장하는 것마다 **갖고 있는 정보**와 **하는 행동**으로 이루어집니다. 아래 표가 나중에 내 프로그램의 구조가 됩니다.

| 이름 | 갖고 있는 정보<br>(예: 위치, 목숨) | 하는 행동 또는 규칙<br>(예: 이동, 점프) |
|---|---|---|
| 🧍 **플레이어** | 체력,영혼 | 공격,방어,선택,영혼(자원) |
| 적 | 체력 | 공격,방어 |
| 이벤트 | 랜덤 | 랜덤 |
| 보스 | 체력 | 공격,방어 |
| 상점 |  | 유물,카드 등을 판매 |

> 플레이어 외에 몬스터, 퍼즐, 아이템, 장애물 등 스테이지 1에 꼭 필요한 것만 적습니다. 부족하면 같은 모양으로 줄을 더 추가해도 돼요.

### 5-3. 입력 방식

> 사용할 입력 방식의 `[ ]`를 `[x]`로 바꾸고, 어떤 입력이 어떤 동작이 되는지 적습니다.

- [x] ⌨️ 키보드
- [x] 🖱️ 마우스

| 입력 | 게임 속 동작 |
|---|---|
| 예: 스페이스 키 | 점프 |
| 숫자키 | 카드선택 |
| shift | 턴종료 |
| 스페이스바 | 확인 |
